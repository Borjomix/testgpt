# Выше

Небольшая браузерная аркада с полётом **вверх**. Оригинальное оформление: мятное небо, лесная долина, парящие острова и оранжевая птица. Всё нарисовано в Canvas; звуки синтезируются через Web Audio. Шрифты хранятся в сборке, внешние API и ключи не нужны.

## Запуск

Требуется Node.js 22.18+ или 24 LTS и npm. В подготовленном облачном окружении установлен Node.js 24.

```bash
cd /workspace/testgpt
npm ci
npm run dev -- --port 5173
```

Vite слушает `0.0.0.0:5173`. Для локальной разработки откройте порт 5173 в браузере. Сервис работает, пока запущен процесс Vite.

```bash
npm run build       # проверка TypeScript и production-сборка в dist/
npm run preview     # проверка production-сборки
npm test            # 10 тестов игровой модели
npm run test:browser # проверки интерфейса и игры в Chromium
```

Для браузерных тестов используется `/usr/bin/chromium`, если он установлен. Другой путь можно передать через `CHROMIUM_PATH`. Если системного Chromium нет, установите браузер Playwright командой `npx playwright install chromium`.

## Управление

- **← / →** или **A / D** — поворот; птица набирает высоту автоматически.
- **Пробел**, **↑** или **W** — ускорение, пока есть энергия.
- **Esc / P** — пауза и продолжение.
- **Enter** — начать полёт или продолжить после паузы.
- **На телефоне** — ведите пальцем по игровому полю либо удерживайте экранные кнопки. Кнопка ветра включает ускорение.

Светлячки пополняют энергию. Столкновение с островом отнимает одну из трёх жизней; после удара действует короткая неуязвимость. Режим «Дзен» позволяет лететь без потери жизней. Рекорды двух режимов хранятся отдельно в localStorage. При переключении вкладки игра автоматически ставится на паузу.

## Устройство проекта

- `src/model.ts` — физика, процедурная генерация, столкновения и очки.
- `src/renderer.ts` — пейзаж, птица, частицы и анимация Canvas.
- `src/main.ts` — интерфейс, управление, пауза и сохранение рекордов.
- `src/audio.ts` — короткие синтезированные звуки.
- `src/style.css` — адаптивный интерфейс для компьютера и телефона.
- `tests/` — тесты модели и браузерные сценарии.

Сборка `dist/` подходит для обычного статического хостинга. Серверная часть не требуется.

## Запуск в Telegram

Игра подготовлена как Mini App: внутри Telegram подключается официальный SDK, окно разворачивается, нативная кнопка «Назад» сначала ставит полёт на паузу, а затем возвращает на старт. Вертикальные жесты не сворачивают Mini App. В обычном браузере SDK не загружается. Если SDK недоступен, игра продолжает работать как обычная веб-страница.

1. Опубликуйте `dist/` на HTTPS-хостинге. В `.github/workflows/pages.yml` подготовлена публикация в GitHub Pages после push в `main`. В настройках репозитория Pages должен быть выбран источник **GitHub Actions**, а тариф и права должны позволять Pages для этого репозитория. Относительные пути ресурсов поддерживают размещение в подпапке `/testgpt/`.
2. Добавьте `TELEGRAM_BOT_TOKEN` через секреты окружения с разрешённым назначением `api.telegram.org`. Он нужен только скрипту настройки; в клиентскую сборку его добавлять нельзя. При работе через прокси нужны разрешения к API Telegram и публичному хосту игры. Для управления публикацией через GitHub нужны доступ к API GitHub и права на репозиторий/Pages.
3. Проверьте доступ к боту без изменений:

   ```bash
   python3 scripts/configure_telegram.py --check
   ```

4. После проверки опубликованной игры настройте кнопку меню:

   ```bash
   python3 scripts/configure_telegram.py --url "$GAME_URL"
   ```

   `GAME_URL` — фактический публичный HTTPS-адрес готовой игры. Скрипт проверяет страницу, задаёт кнопку **Играть** и повторным запросом проверяет сохранение. Он не отправляет сообщения пользователям и не меняет имя или описание бота. Повторный запуск с тем же адресом не перезаписывает уже правильную кнопку.

5. Откройте бота в Telegram и нажмите кнопку **Играть** рядом с полем сообщения. Для кнопки меню не нужен постоянно работающий backend бота. Автоматический ответ на `/start` потребовал бы отдельного сервиса и не входит в эту настройку.

Проверки интеграции:

```bash
python3 -m unittest discover -s tests -p '*_test.py'
npm run test:browser
```

Тесты Telegram используют имитацию SDK и Bot API. Их прохождение не означает, что реальный бот подключён: для этого должны успешно выполниться публикация и скрипт настройки с настоящим секретом.
